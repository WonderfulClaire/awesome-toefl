# 📊 分数体系与目标设定

> 2026 新版托福采用「双轨评分」：传统 **0–120 分制** 继续保留，新增 **1–6 分段制**（0.5 分为增量）。
> 定一个「刚好够用」的目标分，比盲目冲高分更省时间和金钱。

## 一、1–6 分段制是什么？

- 四个单项（阅读/听力/口语/写作）各给一个 **1–6 的分段分**（band score），以 0.5 分为增量；
- **总分 = 四个单项分段分的平均值**；
- 设计目标是与 CEFR（欧洲共同语言参考框架）直接对标，让院校更容易横向比较（雅思考生对这套逻辑会很熟悉）。

### 分段分与 CEFR 对照（近似）

| 分段分 | CEFR 等级 | 大致水平描述 |
| --- | --- | --- |
| 6.0 | C2 | 精通：接近母语者 |
| 5.0–5.5 | C1 | 流利运用：应对学术场景基本无碍 |
| 4.0–4.5 | B2 | 独立运用：多数院校本科/硕士的门槛区间 |
| 3.0–3.5 | B1 | 进阶：日常交流可以，学术场景吃力 |
| 2.0–2.5 | A2 | 基础 |
| 1.0–1.5 | A1 | 入门 |

> ⚠️ 上表为帮助理解的近似对照。你申请的学校认哪条线、两种分制如何换算，**一切以 ETS 官方对照表和学校官网要求为准**。

## 二、如何设定目标分？

三步法：

1. **查要求**：列出你要申请的 3–8 所学校/项目，去官网查语言成绩要求（注意有些项目对**口语单项**有额外要求，尤其是需要做助教 TA 的博士项目）；
2. **取最高**：目标分 = 所有项目要求中的最高值 **+ 一点余量**（120 分制加 3–5 分，分段制加 0.5）；
3. **别贪多**：过了线之后，招生官几乎不会因为你 110 vs 105 而改变决定——把时间省下来打磨文书和 GPA 收益更高。

### 常见目标区间参考（120 分制）

| 申请方向 | 常见要求 |
| --- | --- |
| 美国 Top 30 本科/硕士 | 100+（部分 105+） |
| 美国一般院校 | 79–90 |
| 英联邦/欧陆英语授课项目 | 80–95（很多也接受雅思） |
| 博士助教（TA）岗位 | 常见口语单项要求 |
| 求职/移民加分 | 视具体政策而定 |

## 三、先测出你的基础分

不知道自己几斤几两之前，不要开始制定计划。两种方式：

1. **官方免费模考**（推荐）：ETS 官网提供免费的 Practice Test，最接近真实考试（改革后请认准标注新版格式的模考）；
2. **粗略自估**：如果暂时不方便模考，可用「雅思成绩 / 六级分数 / 词汇量测试」粗估，但误差较大，仅用于选计划档位。

### 基础自查表

| 你的情况 | 大致定位 | 推荐计划 |
| --- | --- | --- |
| 词汇 <5000，六级未过或未考 | 基础期 | [6 个月计划](study-plans.md#六个月计划) |
| 词汇 5000–8000，六级 425–550 | 强化期 | [3 个月计划](study-plans.md#三个月计划) |
| 词汇 8000+，六级 550+ 或雅思 6.5+ | 冲刺期 | [1 个月计划](study-plans.md#一个月计划) |

## 四、关于 MyBest Score（拼分）

ETS 会自动把你**两年内**每个单项的最高分拼成一个 MyBest Score 随成绩单发送。

- ✅ 如果目标学校接受拼分：可以采取「分次突破单项」策略，压力小很多；
- ⚠️ 很多学校**不接受**拼分，只看单次成绩 —— 申请前务必逐校确认。
