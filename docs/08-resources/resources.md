# 🧰 资源汇总：少而精，免费优先

> 收录原则：① 合法合规（不收盗版网盘）；② 免费优先，付费明确标注 💰；
> ③ 每类只推最好的 2–3 个——资源焦虑本身就是备考大敌。

> ⚠️ 2026 改革后，购买任何第三方付费课程/题库前，先确认其已按新版题型更新。

## 📺 视频教程（B 站 & YouTube）

> 视频课的正确用法：**看 1 集 → 练 3 天 → 再看下一集**。连刷 50 集网课≠备考，那叫追剧。
> ⚠️ 2026 改革后，看任何讲「口语 Task 1–4 模板」「独立写作模板」的旧视频前先想一下：这些题型已经没了。

### YouTube（英文授课，一手信息快）

| 频道 | 说明 |
| --- | --- |
| [TOEFL TV（ETS 官方）](https://www.youtube.com/toefltv) | 官方频道：新题型说明、评分标准、家考指南，改革信息的第一视频信源 |
| [TST Prep](https://www.youtube.com/@TSTPrep) | 免费视频里质量最高的一档：题型逐个拆解 + 完整模拟题，新版更新快 |
| [E2 TOEFL](https://www.youtube.com/@E2TOEFL) | 方法论清晰，各单项都有系统播放列表 |
| [NoteFull](https://www.youtube.com/@NoteFullTOEFLMastery) | 老牌托福频道，听力口语讲解细致（注意甄别旧版内容） |

### B 站（中文讲解，适合起步和搞懂难点）

| 内容 | 说明 |
| --- | --- |
| [B 站搜索 #托福](https://search.bilibili.com/all?keyword=%E6%89%98%E7%A6%8F) | 听力/阅读/口语/写作都有高播放合集，认准发布时间新、明确标注新版题型的 |
| 托福听力向 UP 主（如「托福听力黄叔」等） | 精听方法、结构听力讲解干货多，方法论不受改革影响 |
| 学科背景知识科普（天文/地质/艺术史） | 中文快速补背景，听读学科材料时降耗（回形针式科普、纪录片均可） |
| 考情回忆 / 出分经验视频 | 搜「2026 新版托福 考情」看一手考场体验，注意甄别广告软文 |

> 💡 挑视频的三个过滤器：① 发布/更新时间在 2025 年底之后（覆盖新版）；② 讲「能力训练方法」优于讲「技巧套路」；③ UP 主自己考过且晒过分 > 纯机构剪辑号。

## ❌ 避坑清单

1. **盗版资料包**：动辄几十 GB 的「全套资料」，90% 你永远不会打开，还可能携带过期信息；
2. **旧版模板课** 💰：2026 改革后，旧版口语 Task 模板、独立写作模板课已失去价值，别买；
3. **保分班**：「不过退款」的商业模式赌的是概率，不是教学质量；
4. **资料囤积症**：每个单项 1–2 个核心资源用透，胜过 20 个资源各摸一下。
