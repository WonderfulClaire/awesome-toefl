# 📖 词汇篇：托福词汇的最短路径

> 托福需要 **8000–10000** 词汇量。但比数字更重要的是分层：
> 不同层的词，学法完全不同。背错了层，就是在浪费时间。

## 一、托福词汇的三层结构

| 层 | 内容 | 数量级 | 要求 | 学法 |
| --- | --- | --- | --- | --- |
| L1 基础层 | 高中/四级核心词 | ~4500 | 听说读写全能用 | 缺就先补，不能跳 |
| L2 学术层 | 学术通用词（AWL 等） | ~2000 | 读听秒懂，写作能用一部分 | 词表 + 阅读中巩固 |
| L3 学科层 | 天文/地质/生物/艺术史等学科词 | ~1500 | **见到/听到能认出即可**，不需要会拼会用 | 按学科分类突击 |

**最常见的错误**：用背 L1 的力气去背 L3（给 photosynthesis 造句），或者用背 L3 的态度对付 L1（seldom 认识但不会用）。

> ⚠️ 新版阅读的 **Complete the Words** 题型要求补全单词缺失字母 —— 这意味着 L1/L2 层不能只「眼熟」，**拼写也得过关**，纯刷 App 选义项是不够的。

## 二、核心方法：艾宾浩斯 + 多轮快刷

**原则：一个单词见 7 次，好过盯着看 7 分钟。**

### 节奏表（以每天 60 个新词为例）

| 天数 | 任务 |
| --- | --- |
| Day 1 | 新词 List 1 |
| Day 2 | 新词 List 2 + 复习 List 1 |
| Day 3 | 新词 List 3 + 复习 List 2、1 |
| Day 5 | 复习 List 1（第 3 次） |
| Day 8 | 复习 List 1（第 4 次） |
| Day 15 | 复习 List 1（第 5 次） |

嫌麻烦？**直接用 Anki / 任意带间隔重复（SRS）算法的 App**，它替你排好了所有复习节点。

### 快刷的正确姿势

1. 每个词第一遍只看「词形 + 首要中文释义」，3 秒内过；
2. 不认识的标记，认识的划掉——**每轮只刷标记词**，轮次越多剩得越少；
3. 读音必须听：新版听力口语占比高，「哑巴词汇」在考场上等于不认识；
4. L1/L2 层每周抽 20 个词做**拼写自测**（听音写词），应对 Complete the Words。

## 三、词表怎么选？

| 阶段 | 推荐 | 说明 |
| --- | --- | --- |
| 基础不牢 | 四级词表 → 六级词表 | 先把 L1 补齐 |
| 主力阶段 | 任意主流「托福核心词汇」书/App 词表 | 各家核心词表重合度 >80%，**选一个坚持完比选「最好的」重要** |
| 学术加强 | AWL（Academic Word List，570 词族，可免费获取） | 学术写作阅读的性价比之王 |
| 冲刺 | 自建生词本 | 从你自己的错题和精读材料中来，最精准 |

## 四、Anki 使用建议（可选但强烈推荐）

1. 卡片模板：正面 = 单词 + 发音；背面 = 释义 + **你遇到它的原句**；
2. 别下载几万张卡的巨型牌组——**自己造卡的过程就是记忆过程**；
3. 每天固定时段清空到期卡片，10–20 分钟足够；
4. 搭配浏览器划词插件，把阅读中查过的词一键进 Anki。

## 五、词汇自测

- 每月测一次词汇量（如 testyourvocab.com 或任意词汇量测试工具），画出增长曲线；
- 达到 8000 后，把词汇时间从「背新词」转向「阅读中巩固 + 学科词过一遍」。

## 六、学科词速查清单

托福学术材料的高频学科（按出现频率排序），L3 层按此突击：

```
生物（动物行为/生态/进化） > 地质/天文 > 美国历史/考古 >
艺术史（绘画/建筑/音乐） > 心理学 > 商业/经济 > 化学/物理
```

用 [AI 提示词](../07-ai-prep/ai-toolkit.md#词汇类) 可以按学科批量生成带例句的词表。
