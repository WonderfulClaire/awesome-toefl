# 🤖 AI 辅助备考：把大模型变成你的私人外教

> 新版托福的很多题型（造句、邮件、复述、访谈）目前市面上练习题极少——
> 但 AI 恰好能**无限量生成**这些练习并即时批改。用得好，等于免费的一对一。

本页提供三种用法，按顺手程度任选：

| 用法 | 适合谁 | 怎么用 |
| --- | --- | --- |
| 📋 复制提示词 | 所有人 | 复制到任意主流大模型（Kimi / 豆包 / DeepSeek / ChatGPT…），一个用途开一个对话 |
| 🚀 一键直开 | 用 ChatGPT 的人 | 点每条提示词下方的「一键发给 ChatGPT」，提示词自动填入输入框，替换 `{占位符}` 后回车发送 |
| 💻 本地陪练工具 | 想在终端里无限刷题的人 | 仓库自带 [`tools/ai_coach.py`](../../tools/ai_coach.py)，接你自己的 API Key（DeepSeek / Kimi / 通义 / GLM / OpenAI 均可），用法见[本页末尾](#本地陪练工具ai_coachpy) |

## 使用原则

1. **AI 是陪练不是拐杖**：批改后必须自己重写；生成的内容自己先做再看答案；
2. **先建档案再开练**：每个新对话先发下面的「考生档案」，AI 的出题难度和批改口吻会完全不同；
3. **警惕幻觉**：AI 生成的「考试政策/分数要求」类信息不可信，只用它做**语言训练**；政策信息认准 ETS 官网。

## 第 0 步：给 AI 建一份「考生档案」

下面这段**先发**，再发具体训练提示词。它同时启用「错题账本」机制——
本页所有互动型练习的错误都会被 AI 记账，随时说「复盘」就能拿到你的错误模式汇总。
每开一个新对话都粘贴一次（花括号里改成你自己的情况）：

```text
【考生档案】请记住以下信息并贯穿本对话：
- 目标总分：{100}，当前水平：{模考 88 / 六级 550 / 阅读尚可听力偏弱}
- 最薄弱项：{听力细节题、口语流利度}
- 距考试：{6 周}，每天可投入：{2 小时}
- 对我的要求：出题难度贴近但略高于我的水平；批改时直说问题、不要客套和夸奖；
  所有反馈先讲最伤分的那一条。
- 错题账本：本对话中我每答错一次，你就默默记下【题型｜错误原因】；
  当我说「复盘」时，输出完整账本 + 归纳出的 2–3 个错误模式。
```

## 进阶：用 AI 搭建自动化训练流

- **TTS 组合拳**：提示词 8 生成句子 → 用系统自带/在线 TTS 朗读 → 完成「听后复述」闭环训练；
- **Anki 卡片批量生成**：让 AI 把你的生词表转成 Anki 导入格式（`单词<Tab>释义+例句`）；
- **每日一练**：把提示词 3/4/11 收藏起来，每天开一个新对话各来一组，15 分钟完成新题型保温；
- **错题闭环**：练完说「复盘」→ 把账本喂给提示词 17 → 专打自己的弱点，这是 AI 陪练相对刷题册的最大优势。

## 本地陪练工具：ai_coach.py

不想开网页？仓库自带一个**零依赖**的终端陪练工具 [`tools/ai_coach.py`](../../tools/ai_coach.py)，
直接连你自己的大模型 API，内置本页全部提示词：

```bash
# 1. 准备一个 API Key（DeepSeek / Kimi 便宜好用，注册即得）
#    Windows（PowerShell，设置后重开终端）：
setx AI_COACH_API_KEY "sk-你的key"
#    macOS / Linux：
export AI_COACH_API_KEY="sk-你的key"

# 2. 运行（--provider 可选 deepseek / kimi / qwen / glm / openai）
python tools/ai_coach.py --provider deepseek

# 3. 按菜单选训练模式（学科词汇 / 邮件批改 / 模拟访谈……），直接开练
```

特性：

- **选模式即加载提示词**：菜单对应本页 1–18 号提示词，另有自由对话模式；
- **开场自动建档**：启动时引导你填考生档案（目标分/弱项/剩余周数），全程生效；
- **错题账本内置**：随时输入「复盘」查看本次训练的错误模式汇总；
- **接口通吃**：兼容一切 OpenAI 格式接口，`--base-url` + `--model` 可接自建或中转服务；
- **零依赖**：只用 Python 标准库，无需 `pip install` 任何东西；
- 常用命令：`/paste` 粘贴多行文本（作文/错题），`/new` 重开对话，`/mode` 换模式，`/exit` 退出。

> 💰 成本参考：DeepSeek 按当前价格练一小时口语/写作批改，费用通常不到一杯奶茶的零头。
