# 📊 托福写作评分标准（ETS 官方 rubric 拆解）

写作总分 = 综合写作(0–5) + 学术讨论(0–5)，各自换算后相加成 0–30。下面把官方 5 分档的行为描述翻译成「可操作清单」。

---

## 一、综合写作 Integrated（0–5）

| 分数 | 核心表现（来自 ETS rubric） | 你自检时问自己 |
|---|---|---|
| **5** | 准确呈现阅读与听力的关系；三点都覆盖；偶有语言小错但不影响 | 讲座三点是否**逐点反驳**了阅读？ |
| **4** | 关系基本清楚，但某点遗漏/轻微歪曲；语言尚可 | 有没有哪一点只写了阅读没写讲座？ |
| **3** | 只覆盖部分关系，或细节串错；语言错误偏多 | 讲座和阅读有没有「对不上号」？ |
| **2** | 严重遗漏/歪曲；字数严重不足 | 是否把讲座当成了支持阅读？ |
| **1** | 几乎没呈现关系；语言破碎 | — |
| **0** | 跑题 / 只抄阅读 / 空白 | — |

**高分铁律（阅卷人最在意的 3 件事）**
1. **关系必须写「讲座如何对待阅读」**，不是分别总结两篇。高频动词：`challenge / contradict / cast doubt on / undermine / point out the flaw in`。
2. **三点要对应**（阅读第 1 点 ↔ 讲座第 1 点），用分段或衔接词明示。
3. **听力细节 > 阅读细节**。阅读内容可以简写，但讲座的反驳证据要具体（数字、因果、例子）。

> 字数：官方建议 150–225，但 5 分范文常写到 280–320。前提是不水——每句都在推进「反驳」。

---

## 二、学术讨论写作 Academic Discussion（0–5）

| 分数 | 核心表现 | 你自检时问自己 |
|---|---|---|
| **5** | 切题且充分展开；清晰立场+具体理由/例子；语言准确多样 | 我的观点有没有**被例子撑住**？ |
| **4** | 切题、有展开，但例子略泛或语言小错 | 是不是只说"I agree because it's good"？ |
| **3** | 基本切题，但展开不足 / 部分偏题 | 字数够 100+ 吗？有回答教授问题吗？ |
| **2** | 大量偏题、重复、或语言严重受限 | 有没有真的参与讨论而非泛泛而谈？ |
| **1** | 几乎不相关 / 词不达意 | — |
| **0** | 空白 / 纯抄袭同学原话 | — |

**高分铁律**
1. **第一句就亮立场**（同意谁 / 自己的角度），别绕。
2. **至少 1 个具体例子**（个人经历、数据、常识场景）。这是 4→5 的分水岭。
3. **最好「接住」同学那句话**（"Unlike Kelly, I think…" / "Building on Claire's point…"），体现"讨论"而非独白。
4. **10 分钟极限**：结构 = 立场句(1) + 理由1+例子(2–3) + 理由2或让步(1–2) + 收尾(1)。控制在 ~150 词最稳。

---

## 三、两套通用自查清单（写完后 60 秒过一遍）

**综合写作**
- [ ] 开头/首段点明「讲座反驳阅读」了吗？
- [ ] 三个反驳点齐全且一一对应？
- [ ] 每点都写了讲座的**具体证据**？
- [ ] 没把阅读当事实、讲座当补充（方向别反）？

**学术讨论**
- [ ] 第一句亮明立场？
- [ ] 回答了教授的问题（不是另起炉灶）？
- [ ] 有 ≥1 个具体例子？
- [ ] 呼应了同学一句？
- [ ] 无明显语法/拼写崩盘？

---

## 四、常见扣分陷阱

- 综合写作写成「阅读总结 + 听力总结」两截，不写关系。
- 综合写作纠结阅读细节、漏掉听力关键证据。
- 学术讨论只喊口号（"technology is helpful"）不给例子。
- 学术讨论抄同学原话或过度重复教授问题。
- 为凑字数堆套话（"In conclusion, this is a controversial topic" 没用）。
