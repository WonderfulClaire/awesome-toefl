# 🎯 考场实战：把练到的分全部拿回家

> 备考决定上限，考场决定下限。这一章的目标：不因流程、心态、体力问题丢掉任何一分。
> ⚠️ 报名费用、转考政策等以 [ETS 官网](https://www.ets.org/toefl) / [NEEA 报名网](https://toefl.neea.cn/) 实时信息为准。

## 一、报名与选场

1. **提前 2–3 个月报名**：热门城市热门日期紧张，出分高峰期（申请季前）尤甚；
2. **考点怎么选**：优先选去过/评价好的考点（设备新、隔音好）；能实地看一次最好；
3. **线下 vs 家考（Home Edition）**：
   - 线下：环境可控性差一点，但不担心网络与监考软件问题；
   - 家考：省通勤，但需满足房间、设备、网络要求，且部分学校对家考成绩有保留态度——**申请前查目标学校政策**；
4. **留够二战窗口**：首考日期至少比申请截止日早 2 个月，给二战留余地。

## 二、考前一周

- [ ] 作息对齐考试时段（上午考就把每天模考安排在上午）；
- [ ] 做最后一次完整模考（考前 4–5 天，不要考前一天做）；
- [ ] 过一遍错题本 + 口语「人生素材包」+ 邮件/讨论写作常用句式；
- [ ] 确认证件：大陆考生身份证（确认在有效期内），其他地区按官网要求；
- [ ] 打印/截图确认信，查好考点路线，预留 40 分钟以上余量。

## 三、考试日流程与时间管理

新版考试顺序：**阅读 → 听力 → 写作 → 口语**，全程约 90 分钟，紧凑无长休息。

### 各科考场战术卡

**阅读（约 27 分钟）**
- 第一阶段全力保正确率（决定第二阶段难度赛道和分数上限）；
- 单题超过 90 秒 → 选最可能项，放手；
- 结束前 1 分钟：确认没有空题。

**听力（约 27 分钟）**
- 听后选答无文字辅助，**音频只放一遍**，注意力管理是第一要务；
- 上一题没听清 → 3 秒内凭直觉选完，立刻翻篇（沉溺上一题是连环丢分的主因）；
- 短材料别猛记笔记，听懂优先。

**写作（约 23 分钟）**
- 造句题：先确定主谓，再挂修饰成分；
- 邮件：先圈内容点，写完自查是否全覆盖；
- 学术讨论：留 1 分钟检查语法，尤其三单和时态。

**口语（约 8 分钟）**
- 最后一科，也是最考体力的一科——前面留点精神；
- 复述题：卡壳不清零，保主干继续说；
- 访谈题：首句复述问题，框架走完 45 秒。

### 体力与心态

1. 早餐吃熟悉的、抗饿的；考前 30 分钟别再看新材料；
2. 遇到「感觉变难」→ 想起这是自适应的好信号；
3. 某一题崩了 → 新版单题分值低，一题的损失远小于连锁心态崩盘；
4. 设备问题（耳机无声、屏幕卡死）→ 立即举手找监考，流程中断可以恢复，不算你的时间。

## 四、出分与送分

- **出分时间**：新版考试出分显著加快（72 小时内）；
- **免费送分**：报名时可选若干免费送分学校，考前设置好（考后送分要收费）；
- **MyBest Score**：自动随成绩单发送，学校是否认拼分需逐校确认；
- **复议**：口语/写作可申请复议（有费用，分数可能升也可能降），除非你确信机评/人评严重偏离水平，一般不建议。

## 五、要不要二战？决策树

```
出分 ≥ 目标分？
├─ 是 → 收工！把时间还给文书和 GPA
└─ 否 → 差距多少？
    ├─ ≤ 5 分（120 分制）→ 值得快速二战：保持手感，2–4 周内约考
    ├─ 6–15 分 → 按模考诊断补弱项 1–2 个月再战
    └─ > 15 分 → 回到分项突破阶段，别急着报名；
                 同时检查：目标分是否定高了？（见「分数体系」篇）
```

二战策略：**只攻最弱单项**（如果学校认 MyBest Score，压力更小）；同时复盘首战的非实力丢分（紧张？时间分配？设备？）——这些往往比语言能力更快修复。
